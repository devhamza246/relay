Relay

A support agent that answers from a help center with citations, and hands off to a person with full context when it should not answer.

Demo. Fernwick Goods, its help center, customers and orders are fictional; the order API is a mock. Conversations are deleted after 24 hours. Do not enter real personal data.

1. Try it

Each button starts a new chat and sends that message. The chat opens at the bottom right; you can also type your own.

2. What the agent decided

Send a message to see triage, retrieval, tools and timing for the latest turn.

3. What the human agent receives

When the conversation is handed off, the ticket and the exact Slack message appear here. Try “Billing dispute”.
